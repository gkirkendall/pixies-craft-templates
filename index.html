Free motion templates for EffectCraft: maps, lower thirds, titles, logos and overlays. Each row shows all of a template's styles in one picture and a demo reel that names the feature on screen.

The templates together

How to install

  1. Get EffectCraft 0.13 or later: getartcraft.com/apps/effectcraft.
  2. Download: every template in one ZIP, with their fonts and a README; or one template at a time with its download link below (16x9, 9x16).
  3. Install the fonts: in the ZIP's fonts folder, or each template's Fonts link below; double-click a font file to install it (on Linux, copy it to ~/.local/share/fonts). All are free (SIL Open Font License). EffectCraft swaps a missing font for its own.
  4. Use it: in EffectCraft, File ▸ Import ▸ Essential Graphics Template…, then change its text, colours, fonts and timing in the Essential Graphics panel.
  5. From a script (for tools that make videos): tools/render.py; see Using a template in the README.
