# Locator

Zooms from a whole country to one place, then a pin, the place name and a subtitle appear; full frame or a corner card.

Each folder below is complete and works on its own. Use the one tested with your EffectCraft version; `tools/render.py`
chooses it for you (`--which` shows the choice). The details, controls and examples are in each folder's README.

| Folder | Tested with EffectCraft | Template version | Status |
|---|---|---|---|
| [effectcraft-0.13](effectcraft-0.13/README.md) | 0.13.0–0.14.0 | 2.0.0 | current |

Written by `tools/catalog.py` from the test records `tools/verify.py` keeps; do not edit by hand.
