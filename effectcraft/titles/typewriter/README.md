# Typewriter

Text that types itself letter by letter with a blinking cursor, and can erase itself again; the finished line is centred.

Each folder below is complete and works on its own. Use the one tested with your EffectCraft version; `tools/render.py`
chooses it for you (`--which` shows the choice). The details, controls and examples are in each folder's README.

| Folder | Tested with EffectCraft | Template version | Status |
