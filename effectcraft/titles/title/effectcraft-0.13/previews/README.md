# Demo reel

`demo.mp4` (and `demo_9x16.mp4` where there is one) shows this template at work; `poster.jpg` is its still. They are made by
`tools/demo.py` from the `demo*.json` beside them, and `tools/verify.py --footage DIR --music DIR` remakes and compares them.
